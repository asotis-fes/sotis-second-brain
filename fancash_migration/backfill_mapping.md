# Backfill mapping — Scylla → PG `transaction` (ENTDATA-2021)

Source of truth for the Task 2 historical backfill transform. Copied from ENTDATA-2021
(reporter Anna Smith, updated 2026-08-20). **Verify against the live ticket before executing** —
several rules are TBD. FanCash = `program_id = 1`.

## Column mapping → `transaction`

| Scylla | PG | Rule |
|--------|----|------|
| `loyalty_account_id` | `loyalty_id` | Pre-resolved in the export. No mapping → quarantine |
| `loyalty_txn_id` | `transaction_id` | **TBD** — some transformation required |
| — | `program_id` | `1` |
| `txn_status` (+ `loyalty_txn_type` for VOID) | `type` | Per status table below. **Not** from `loyalty_txn_type` alone |
| `txn_amount` | `amount` | 6dp already. CHECK > 0 → use `abs()` |
| `creation_time` | `created_at` | Partition key, UTC |
| `loyalty_expiration` | `expires_at` | ADD only |
| — | `available_at` | `= created_at` |
| `loyalty_txn_add_type` | `entry_type` | ADD only. `PROMOTION`/`PARTNER_PROMOTION` → `PROMO`, else `BASE`. Enum = `BASE`/`PROMO`/`GIFT`/`PURCHASE` — no `GOODWILL` (that's a reason) |
| `loyalty_txn_reason_desc` + status | `reason` | Map scylla reason → new reason (Confluence 2771091472). Ask **Will Mack** / **Christine Nichols** for final list |
| `site_id` | `site_id` | direct |
| `tenant_id` | `tenant_id` | Only ever `0` or NULL in QC — **derive from `site_id`** |
| `order_id` | `ref_id` + `ref_id_type` | `ORDER_ID`. `ref_id_type` also allows `BET_ID` — usable for `SPORTS_BOOK_BETTING_<id>` rows |
| ref data → `externalReferenceId` | `external_id` | fallback `order_id`, then `loyalty_txn_id` |
| `fancash_balance` | `metadata.balance` | `{"balance": {"available": 4.000000, "pending": 0.000000}}` — 6dp, balance **after** the txn. Kept for reconciliation |
| — | `actor` | `'legacy_migration'` |
| ref data → `localization` | `jurisdiction` | format: `US-NJ` |
| `loyalty_txn_id` | `reversed_transaction_id` | VOID/REFUND → the **same** `transaction_id` as the row it reverses (they share `loyalty_txn_id`). NULL otherwise |

> `transaction.id` (UUIDv7) is generated by ingest, **not** exported.

## Status token → PG `type`

| status token | PG `type` | note |
|--------------|-----------|------|
| `ADD` | `ADD` | 92% of rows |
| `AUTH` | `AUTH` | |
| `CAPTURE` | `CAPTURE` | counters observed up to `CAPTURE_10` — partial captures are real |
| `VOID` + `loyalty_txn_type = 1` | `VOID` | void of an auth |
| `VOID` + `loyalty_txn_type = 0` | `VOID` | void of an earn (VOID_ADD); often `add_type = 5` CLAWBACK |
| `REFUND` | `ADD` | credit back; only `loyalty_txn_type = 0` seen, ~0.003% of rows |
