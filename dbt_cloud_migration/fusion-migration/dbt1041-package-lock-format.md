# dbt1041 — Old-format `package-lock.yml`

## What the warning looks like

```
[warning] [FmtError (dbt1041)]: Old format package-lock.yml file found.
  Please provide package definitions.
```

## Root cause

We initially copied `package-lock.yml` verbatim from `fes-airflow/dags/dbt/package-lock.yml`. That lockfile was generated by dbt-core 1.8 and uses the older lockfile schema. Fusion has a new format.

## Fix

`dbt-autofix packages` regenerates the file. Alternatively, `dbt deps` in the Fusion CLI (or dbt Cloud IDE) writes a fresh Fusion-format lockfile on next invocation.

We ran `dbt deps` in the Fusion CLI after cleanup, which produced a Fusion-format lockfile automatically. The warning cleared.

## Migration approach

One-time `dbt deps` invocation with Fusion. No code changes needed. Commit the regenerated lockfile.
